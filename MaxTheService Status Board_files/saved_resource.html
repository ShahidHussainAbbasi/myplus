04Cheap and unclaimed — highest value per minute

The microservices are not running the prod profile

SPRING_PROFILES_ACTIVE is set on the monolith and on none of the microservices. They run the default config, where org.hibernate.SQL is DEBUG and org.hibernate.orm.jdbc.bind is TRACE.

application-prod.yml already sets both to WARN — it is simply never activated. Thousands of log lines per heavy request, and bound parameters mean customer data is written to container logs. One line per service in compose.
